# airbnb-fullstack

Aplicação Full Stack inspirada no Airbnb, desenvolvida como projeto pessoal para estudo e prática de integração entre frontend e backend.

O projeto encontra-se em desenvolvimento.

---

## Visão Geral

A aplicação implementa funcionalidades essenciais de uma plataforma de anúncios, incluindo cadastro e autenticação de usuários, gerenciamento de anúncios e comunicação entre frontend e backend por meio de uma API REST.

---

## Tecnologias Utilizadas

### Frontend
- React
- Axios
- Tailwind CSS
- Vite

### Backend
- Node.js
- Express
- MongoDB
- Mongoose
- CORS
- Bcrypt (criptografia de senhas)

---

## Funcionalidades Implementadas

- Cadastro e autenticação de usuários  
- Criptografia de senhas com bcrypt  
- CRUD de anúncios  
- Integração frontend-backend via API REST  
- Consumo de API utilizando Axios
